# Work Survivors: versão de teste (navegador)

Build Web do jogo para a equipe testar no navegador. O código fica no repositório privado `work-survivors`.

**Jogar:** https://lucasroso0.github.io/Work-Survivors-testes/

Versão do código: `v0.4.0` (`798ebb3`, branch main)

## Celular
Jogue com o celular **na horizontal**. O joystick aparece onde o dedo encostar e fica parado ali enquanto o dedo estiver na tela; o botão ❚❚ no canto pausa (na pausa ficam o volume, a música e a tremida de tela). O som começa depois do primeiro toque. Para ficar em tela cheia, use **Opções → Tela cheia** no menu inicial ou o botão no menu de pausa.

## Controles
| Ação | Teclado |
|------|---------|
| Menu inicial: escolher opção | ↑↓ + Enter (ou toque) |
| Cartão de ponto: escolher campo / mudar valor | ↑↓ / ←→ (ou os botões ◀ ▶) |
| Cartão de ponto: voltar ao menu | Esc |
| Bater o ponto | Enter |
| Mover | WASD ou setas |
| Escolher upgrade / comprar | Setas + Enter (ou mouse/toque) |
| Pausar (som, música, tremida de tela, tela cheia, código do dia, sair) | Esc ou P (no celular, botão ❚❚; no controle, Start) |
| Acelerar o tempo 8× (teste) | F3 (aperte de novo para voltar ao normal) |

Obs.: clique uma vez na tela do jogo antes de usar o teclado. O primeiro carregamento baixa cerca de 45 MB.

## Controle (Steam Deck, controle no celular ou no PC)
Aperte um botão do controle depois de abrir a página (o navegador só detecta o controle a partir daí). **A** confirma, **B** volta, **Start** ou **Select/View** pausam, **analógico esquerdo ou direcional** andam e navegam nos menus. No Steam Deck, use o layout **Gamepad** do Steam Input no navegador.

## O que mudou nesta versão
- **Mais difícil:** vida e velocidade novas (Lucas 80 / 100, Pabllo 75 / 125, Alexandre 55 / 75), armas com **25% menos dano base** e a classe sem bônus inicial (só +0,5% por nível).
- **Armas de outro personagem** (da Caixa de hardware) dão **45% do dano**.
- **Alexandre:** mais lento, com menos dano próprio; o hack carrega a cada 15 abates e o **roubo de vida a cada 25**. Na névoa hacker ele não usa armas.
- **Pabllo:** a Bolsa de Bugigangas gira num círculo de 35 px (o alcance aumenta; a velocidade de ataque acelera a rotação). No **Modo anime** ele grita "IA MA TE CU DA SAI", solta corações e a aura dá **2x o dano atual** dele (não mata mais na hora).
- **Lucas:** no Modo Tank fica **flexionando os braços** e, ao soltar, abre os braços gritando **"IMPACTO METEORO!"**.
- **Wiper:** fica bem mais resistente a cada item que come e nunca morre com um golpe só.
- **Chamados (totens):** têm um **prazo escondido**. Demorou demais? O chamado vence e você perde 15 de Vale-refeição.
- Falas dos personagens mais espaçadas.
- **Copiar código do dia** no Refeitório, **Colar** no Continuar dia e **Tela cheia** no canto do menu.
- **Suporte a controle** com vibração.
