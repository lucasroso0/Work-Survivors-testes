# Work Survivors: versão de teste (navegador)

Build Web do jogo para a equipe testar no navegador. O código fica no repositório privado `work-survivors`.

**Jogar:** https://lucasroso0.github.io/Work-Survivors-testes/

Versão do código: `92c46db`

## Celular
Jogue com o celular **na horizontal**. O joystick aparece onde o dedo encostar; o botão ❚❚ no canto pausa. Para ficar em tela cheia, use o botão **Tela cheia** no cartão de ponto ou no menu de pausa.

## Controles
| Ação | Teclado |
|------|---------|
| Cartão de ponto: escolher campo / mudar valor | ↑↓ / ←→ |
| Bater o ponto | Enter |
| Mover | WASD ou setas |
| Escolher upgrade / comprar | Setas + Enter (ou mouse/toque) |
| Pausar | Esc ou P (no celular, botão ❚❚) |
| Acelerar o tempo 8× (teste) | F3 (aperte de novo para voltar ao normal) |

Obs.: clique uma vez na tela do jogo antes de usar o teclado. O primeiro carregamento baixa cerca de 45 MB.
