# Work Survivors: versão de teste (navegador)

Build Web do jogo para a equipe testar no navegador. O código fica no repositório privado `work-survivors`.

**Jogar:** https://lucasroso0.github.io/Work-Survivors-testes/

Versão do código: `dbea4c3` (branch main: 2ª rodada de UX, com a batida de ponto animada, cenário com faíscas, luz do dia e a Senhorinha da copa)

## Celular
Jogue com o celular **na horizontal**. O joystick aparece onde o dedo encostar e fica parado ali enquanto o dedo estiver na tela; o botão ❚❚ no canto pausa (na pausa ficam o volume, a música e a tremida de tela). O som começa depois do primeiro toque. Para ficar em tela cheia, use **Opções → Tela cheia** no menu inicial ou o botão no menu de pausa.

## Controles
| Ação | Teclado |
|------|---------|
| Menu inicial: escolher opção | ↑↓ + Enter (ou toque) |
| Cartão de ponto: escolher campo / mudar valor | ↑↓ / ←→ (ou os botões ◀ ▶) |
| Cartão de ponto: voltar ao menu | Esc |
| Bater o ponto | Enter |
| Mover | WASD ou setas |
| Escolher upgrade / comprar | Setas + Enter (ou mouse/toque) |
| Pausar (som, música, tremida de tela, tela cheia, código do dia, sair) | Esc ou P (no celular, botão ❚❚) |
| Acelerar o tempo 8× (teste) | F3 (aperte de novo para voltar ao normal) |

Obs.: clique uma vez na tela do jogo antes de usar o teclado. O primeiro carregamento baixa cerca de 45 MB.

## O que mudou nesta versão
- **Menu inicial** com Continuar dia, Novo dia, Reunião de alinhamento e Opções.
- **O dia é salvo sozinho ao sair do Refeitório** (almoço e lanche). Saiu à tarde? **Continuar dia** volta às 13:00 ou 15:30. O dia também vira um **código** (`WS1-...`), no menu e na pausa: guarde para continuar em outro aparelho ou se o navegador apagar os dados.
- **Cartão de ponto maior**, com botões grandes para o toque.
- **Morte:** o Chefe diz "Faleceu, contrata outro.", só 25% do Vale-refeição vira budget e você vai para a **Reunião de feedback** antes de tentar de novo.
- **Dificuldade por terço do dia:** XP 50% / 75% / 100% e inimigos 100% / 125% / 150% de vida e dano. Café e Pendrive caem 25% menos, loja e Reunião 25% mais caras, Supervisor chega com 90 inimigos.
- Nas habilidades (Modo anime, Modo Tank, névoa hacker) a aura virou uma **silhueta piscando que pulsa para fora** do personagem.
- **Músicas novas:** menu, Refeitório e chefe final (também na hora extra).
