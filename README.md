# Work Survivors: versão de teste (navegador)

Build Web do jogo para a equipe testar no navegador. O código fica no repositório privado `work-survivors`.

**Jogar:** https://lucasroso0.github.io/Work-Survivors-testes/

Versão do código: `f0dc587` (branch feat/ux-rotacao-chefe, PR #2 ainda não mesclado)

## Celular
Jogue com o celular **na horizontal**. O joystick aparece onde o dedo encostar e fica parado ali enquanto o dedo estiver na tela; o botão ❚❚ no canto pausa (na pausa ficam o volume, a música e a tremida de tela). O som começa depois do primeiro toque. Para ficar em tela cheia, use o botão **Tela cheia** no cartão de ponto ou no menu de pausa.

## Controles
| Ação | Teclado |
|------|---------|
| Cartão de ponto: escolher campo / mudar valor | ↑↓ / ←→ |
| Bater o ponto | Enter |
| Mover | WASD ou setas |
| Escolher upgrade / comprar | Setas + Enter (ou mouse/toque) |
| Pausar (som, música, tremida de tela, tela cheia) | Esc ou P (no celular, botão ❚❚) |
| Acelerar o tempo 8× (teste) | F3 (aperte de novo para voltar ao normal) |

Obs.: clique uma vez na tela do jogo antes de usar o teclado. O primeiro carregamento baixa cerca de 45 MB.

## O que mudou nesta versão
- A cada hora entra um tipo novo de malware (cartão "NOVO NA REDE") e os antigos vão sumindo.
- O DDoS chega às 17:15 e **precisa ser derrotado**. Se ele estiver de pé às 18:00, começa a **hora extra** (−2 VR por minuto do jogo) até ele cair.
- A Caixa de hardware ficou maior, tem seta na borda da tela e é a prioridade do Wiper (derrote-o para recuperar).
- Interface nova: avisos curtos com ícone no canto, relógio de monitor, crachá, sons e música.
